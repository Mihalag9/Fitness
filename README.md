# Fitness Club Management System

Это веб-приложение для автоматизации управления фитнес-клубом, разработанное в рамках курсовой работы.

---

## Стек технологий

*   **Backend:** .NET 8.0 (ASP.NET Core Web API)
*   **Database ORM:** Entity Framework Core 8.0
*   **Database:** PostgreSQL
*   **API Documentation:** Swagger / OpenAPI
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript

---

## 📂 Структура проекта

```text
/
├── Controllers/      # Контроллеры API для обработки запросов
├── Models/           # Модели данных и сущности базы данных
├── Services/         # Бизнес-логика приложения
├── wwwroot/          # Фронтенд (HTML, CSS, JS)
├── SQL/              # Скрипты для работы с базой данных
├── Properties/       # Конфигурация запуска
└── Program.cs        # Точка входа и настройка пайплайна
```

---

## Системные требования

*   **.NET SDK 8.0** или выше
*   **PostgreSQL** сервер
*   Любой современный веб-браузер

## Начало работы

### 1. Клонирование репозитория
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd Fitness
```

### 2. Настройка базы данных
1. Убедитесь, что ваш PostgreSQL сервер запущен.
2. Создайте базу данных для проекта.
3. Откройте файл `appsettings.json` и настройте строку подключения (`DefaultConnection`) к вашей базе данных PostgreSQL.

### 3. Запуск

#### Через Visual Studio / VS Code
1. Откройте папку проекта в **Visual Studio** или **VS Code**.
2. Убедитесь, что у вас установлены расширения для .NET (для VS Code необходимо расширение *C# Dev Kit*).
3. Нажмите кнопку **Run** (или клавишу **F5**).

#### Через терминал
Для запуска приложения из командной строки используйте:
```bash
dotnet run
```

После успешного запуска приложение откроет в браузере стартовую страницу, которая автоматически перенаправит вас в **Swagger UI** (для тестирования API) и на страницу **абонементов** (`abonnements.html`).
